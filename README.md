# IPL Match Winner Predictor

A Machine Learning project that predicts IPL match winners using historical IPL data.

## Features

- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- Machine Learning Models
- Streamlit Web App (Upcoming)
- Automation using n8n (Upcoming)

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Git & GitHub
